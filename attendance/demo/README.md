# Three.js 简洁打卡示范

在项目根目录运行 `python3 -m http.server 5077 --bind 127.0.0.1 --directory attendance/demo`，浏览器打开 http://127.0.0.1:5077/。

独立交互原型，包含程序生成的和服卡通人物、腰部鞠躬、花瓣、签到与签退弹窗、员工切换。演示记录仅保存在当前页面内存，刷新清空，不访问正式考勤接口。每名示例员工可分别签到、签退；人物区右下角可预览动画，弹窗可重播。页面仅保留人物、时间、员工选择和打卡按钮；人物重新设计为栗棕长发、琥珀色动漫眼睛、杏桃山茶花和服与鼠尾草绿腰带；模型与纹样由本项目代码生成，未使用参考素材的模型或纹理。

Three.js 0.180.0 已放入 vendor，保留 MIT 许可证，无运行时外网依赖。尊重系统减少动态效果设置；不支持 WebGL 时降级显示文字，打卡演示仍可操作。

此版本仅实现示范页，原有后台和考勤规则未改动。接入正式系统时，成功动画必须在服务器确认写入后播放。
